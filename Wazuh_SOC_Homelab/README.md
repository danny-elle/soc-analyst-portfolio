#  Wazuh SOC Homelab

## Overview
My homelab simulates a Security Operations Center (SOC) environment using Wazuh SIEM for log analysis, alerting and incident detection.

## Goals
- Build hands on SOC experience
- Practice alert triage and incident response
- Analyze logs and detect threats

## Environment
- Wazuh server (Ubuntu)
- Endpoint agents (Windows 11/Kali Linux)
- Virtual Machines (VirtualBox)

## Labs
- Wazuh server configuration
- Endpoint agent deployment
- Brute force attack detection
